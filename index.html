คู่มือ Ghostty ฉบับใช้งานจริง

Ghostty เป็น terminal บน Mac ที่เร็วและเบา ทำงานแบบแอป Mac แท้ และแบ่งจอ เปิดแท็บ หรือเปิด terminal แบบดรอปดาวน์ได้โดยไม่ต้องลงอะไรเพิ่ม

อ้างอิง Ghostty 1.4.0 บน macOS · ปุ่มลัดทุกตัวตรวจจาก ghostty +list-keybinds --default · ⌘ = Command, ⌥ = Option, ⌃ = Control, ⇧ = Shift

1Ghostty คืออะไร

Ghostty ใช้แทน Terminal.app หรือ iTerm2 ได้ สิ่งที่ทำให้มันต่างจากตัวอื่นคือ

  • เร็ว: วาดหน้าจอด้วย GPU (Metal) ทำให้ log ยาวๆ หรือ output เยอะๆ ไม่กระตุก
  • เป็นแอป Mac แท้: แท็บ, เมนู, ปุ่มลัด ⌘ และการแบ่งจอทำงานแบบเดียวกับแอป Mac ทั่วไป
  • ค่าเริ่มต้นใช้ได้เลย: ไฟล์ config ว่างก็ใช้งานได้ปกติ แล้วค่อยปรับเฉพาะที่อยากเปลี่ยน
  • มี theme ในตัวกว่า 800 แบบ: ไม่ต้องไปดาวน์โหลดเพิ่ม
ถ้าใช้ tmux อยู่แล้วก็ใช้คู่กันได้ ให้ Ghostty แบ่งจอบนเครื่องตัวเอง และใช้ tmux สำหรับงานที่ต้องเปิดค้างไว้หรือต่อผ่าน SSH (คู่มือ tmux)

2แท็บและหน้าต่าง

ปุ่มทำอะไร
⌘ Tเปิดแท็บใหม่
⌘ Nเปิดหน้าต่างใหม่
⌘ 1 … 8ไปแท็บที่ 1–8
⌘ 9ไปแท็บสุดท้าย
⌘ ⇧ [ / ]ไปแท็บก่อนหน้า / ถัดไป (⌃ Tab ก็ใช้ได้)
⌘ Wปิดช่องที่กำลังใช้ (ถ้ามีช่องเดียวจะปิดทั้งแท็บ)
⌘ ⌥ Wปิดทั้งแท็บ
⌘ ⇧ Wปิดทั้งหน้าต่าง
⌘ Zย้อนการปิดแท็บหรือช่องที่เพิ่งปิด (⌘ ⇧ T ก็ได้)
⌘ Enterเต็มจอ

แท็บและหน้าต่างใหม่จะเปิดในโฟลเดอร์เดียวกับช่องที่ใช้อยู่ (ค่า window-inherit-working-directory = true) จึงไม่ต้อง cd ซ้ำ

3แบ่งจอ (split)

ปุ่มทำอะไร
⌘ Dแบ่งจอ เพิ่มช่องใหม่ทางขวา
⌘ ⇧ Dแบ่งจอ เพิ่มช่องใหม่ด้านล่าง
⌘ ⌥ ←↑↓→ย้ายไปช่องทางซ้าย/บน/ล่าง/ขวา
⌘ [ / ]ไปช่องก่อนหน้า / ถัดไป
⌘ ⌃ ←↑↓→ขยายหรือหดขนาดช่อง
⌘ ⌃ =ปรับทุกช่องให้เท่ากัน
⌘ ⇧ Enterขยายช่องนี้เต็มแท็บชั่วคราว (zoom) กดซ้ำเพื่อคืนขนาดเดิม

ช่องที่ไม่ได้ใช้อยู่จะดูจางลงเล็กน้อย (unfocused-split-opacity = 0.7) จะได้เห็นว่ากำลังพิมพ์อยู่ในช่องไหน ถ้าอยากใช้เมาส์ก็ลากเส้นแบ่งเพื่อปรับขนาด หรือคลิกเลือกช่องได้

4ค้นหา · เลื่อน · ก๊อปปี้

ปุ่มทำอะไร
⌘ Fค้นหาข้อความในหน้าจอและประวัติที่เลื่อนผ่านไป
⌘ G / ⌘ ⇧ Gไปผลค้นหาถัดไป / ก่อนหน้า
⌘ Eค้นหาคำที่เลือกไว้
Escปิดช่องค้นหา
⌘ ↑ / ↓กระโดดไปคำสั่งก่อนหน้า / ถัดไป (ข้าม output ยาวๆ)
⌘ Home / Endไปบนสุด / ล่างสุด
⌘ Kล้างหน้าจอ
⌘ C / ⌘ Vก๊อปปี้ / วาง
⌘ ⇧ Jวางเนื้อหาทั้งหน้าจอเป็นไฟล์ชั่วคราว (เหมาะกับ output ยาว)
⌘ ⌥ ⇧ Jเปิดเนื้อหาทั้งหน้าจอเป็นไฟล์ในโปรแกรมแก้ไขข้อความ

การกระโดดระหว่างคำสั่งด้วย ⌘ ↑ ต้องใช้ shell integration ซึ่ง Ghostty ติดตั้งให้เองใน zsh, bash และ fish (shell-integration = detect)

ในบรรทัดคำสั่ง ⌘ ←/→ ไปต้นหรือท้ายบรรทัด ⌥ ←/→ ข้ามทีละคำ และ ⌘ ⌫ ลบทั้งบรรทัด

5Command Palette

กด ⌘ ⇧ P แล้วพิมพ์ชื่อคำสั่งที่ต้องการ เช่น split, theme, title ถ้าจำปุ่มลัดไม่ได้ ให้ใช้วิธีนี้

ตั้งชื่อแท็บ: เปิด palette แล้วพิมพ์ title (คำสั่ง prompt_surface_title) เช่นตั้งเป็น server / logs / claude จะหาแท็บที่ต้องการได้ง่ายขึ้น

6ไฟล์ config

  1. กด ⌘ , เพื่อเปิดไฟล์ config
  2. แก้ไขแล้วเซฟ
  3. กด ⌘ ⇧ , เพื่อโหลด config ใหม่โดยไม่ต้องปิดแอป

บน Mac ไฟล์อยู่ที่

~/Library/Application Support/com.mitchellh.ghostty/config.ghostty

ถ้าสร้างไฟล์ไว้ที่ ~/.config/ghostty/config.ghostty Ghostty ก็จะอ่านให้เช่นกัน รูปแบบไฟล์เป็น ชื่อ = ค่า บรรทัดละหนึ่งค่า และบรรทัดที่ขึ้นต้นด้วย # เป็นคอมเมนต์ ตัวอย่างชุดเริ่มต้นที่ใช้ได้ทันที:

# ---- หน้าตา ----
theme = light:Catppuccin Latte,dark:Catppuccin Mocha
font-family = JetBrains Mono
font-size = 14
window-padding-x = 10
window-padding-y = 8
background-opacity = 0.95
background-blur = true

# ---- การใช้งาน ----
# ให้ Option ทำงานเป็น Alt (ใช้กับ tmux/vim)
macos-option-as-alt = true
# เลือกข้อความแล้วก๊อปปี้ทันที
copy-on-select = clipboard
mouse-hide-while-typing = true
# เปิดแอปใหม่แล้วได้หน้าต่าง/แท็บเดิมคืน
window-save-state = always

# ---- Quick Terminal ----
keybind = global:cmd+grave_accent=toggle_quick_terminal
ห้ามเขียนคอมเมนต์ต่อท้ายบรรทัด เช่น font-size = 14 # ใหญ่ขึ้น Ghostty จะอ่าน # ใหญ่ขึ้น เป็นส่วนหนึ่งของค่าแล้วแจ้งว่าค่าไม่ถูกต้อง ให้เขียนคอมเมนต์ไว้บรรทัดของตัวเองเท่านั้น
อย่าก๊อปปี้ค่าเริ่มต้นทั้งหมดมาใส่ คู่มือของ Ghostty ระบุว่าค่าเริ่มต้นบางตัวขัดกันเองเมื่อตั้งค่าลงไฟล์ตรงๆ ให้ใส่เฉพาะค่าที่ต้องการเปลี่ยน ถ้าต้องการดูว่ามีค่าอะไรให้ตั้งบ้าง ใช้คำสั่ง ghostty +show-config --default --docs

ค่าบางตัวโหลดใหม่ระหว่างที่แอปเปิดอยู่ไม่ได้ ถ้าแก้แล้วไม่เห็นผล ให้เปิดหน้าต่างใหม่ หรือปิดแอปด้วย ⌘ Q แล้วเปิดใหม่

7เปลี่ยน theme และฟอนต์

Theme

ghostty +list-themes

คำสั่งนี้เปิดหน้าดูตัวอย่าง theme แบบเลื่อนดูได้ (ในเครื่องนี้มี 819 แบบ) เลือกชื่อที่ชอบแล้วใส่ใน config เช่น

theme = Catppuccin Mocha

ถ้าต้องการให้เปลี่ยนตามโหมดสว่าง/มืดของ Mac ให้ใส่ทั้งสองแบบ:

theme = light:Catppuccin Latte,dark:Catppuccin Mocha

ชุดที่คนใช้กันเยอะ ได้แก่ Catppuccin, Dracula, Gruvbox, Tokyo Night, Nord, Rose Pine

ฟอนต์

ghostty +list-fonts      # ดูฟอนต์ที่ติดตั้งในเครื่อง

ใส่ชื่อฟอนต์ใน font-family ถ้าไม่ได้ตั้ง Ghostty จะใช้ฟอนต์ในตัวซึ่งรองรับไอคอน Nerd Font อยู่แล้ว และปรับขนาดชั่วคราวได้ด้วย ⌘ + / ⌘ - / ⌘ 0

8Quick Terminal (terminal แบบดรอปดาวน์)

Quick Terminal คือ terminal ที่เลื่อนลงมาจากขอบบนจอเมื่อกดปุ่ม และซ่อนกลับเมื่อกดซ้ำ ใช้ได้ทุกเวลาแม้กำลังใช้แอปอื่นอยู่ ค่าเริ่มต้นยังไม่มีปุ่มลัด ต้องตั้งเองใน config:

keybind = global:cmd+grave_accent=toggle_quick_terminal
# หรือ bottom / left / right / center
quick-terminal-position = top

หลังตั้งแล้ว กด ⌘ ` (ปุ่มที่อยู่ใต้ Esc)

ปุ่ม global: ต้องได้รับสิทธิ์ Accessibility ตอนกดครั้งแรก macOS จะถามสิทธิ์ ถ้าไม่ขึ้นให้ไปที่ System Settings → Privacy & Security → Accessibility แล้วเปิดให้ Ghostty

9ตั้งปุ่มลัดเอง

รูปแบบคือ keybind = ปุ่ม=คำสั่ง ดูชื่อคำสั่งทั้งหมดได้จาก ghostty +list-actions

# ปุ่มเดียว
keybind = cmd+shift+r=reload_config

# กดต่อกันเป็นลำดับ (แบบ prefix ของ tmux): กด ctrl+a แล้วตามด้วย n
keybind = ctrl+a>n=new_tab

# ยกเลิกปุ่มลัดเดิมของ Ghostty เพื่อส่งปุ่มนั้นให้โปรแกรมใน terminal
keybind = cmd+k=unbind
prefixความหมาย
global:ใช้ได้แม้ Ghostty ไม่ได้อยู่ด้านหน้า (ต้องได้สิทธิ์ Accessibility)
all:สั่งกับทุกช่องพร้อมกัน
unconsumed:ทำคำสั่งของ Ghostty แล้วส่งปุ่มต่อให้โปรแกรมใน terminal ด้วย

ดูปุ่มลัดทั้งหมดที่ใช้งานอยู่ได้ด้วย ghostty +list-keybinds

10คำสั่ง ghostty +…

ถ้าพิมพ์ ghostty แล้วไม่เจอคำสั่ง ให้ใช้ path เต็ม หรือเพิ่ม alias ใน ~/.zshrc:

alias ghostty=/Applications/Ghostty.app/Contents/MacOS/ghostty
คำสั่งทำอะไร
+versionดูเวอร์ชัน
+list-themesดูตัวอย่าง theme
+list-fontsดูรายการฟอนต์
+list-keybindsดูปุ่มลัดที่ใช้อยู่ (--default = ค่าเริ่มต้น)
+list-actionsดูชื่อคำสั่งที่ใช้ตั้งปุ่มลัดได้
+show-configดูค่าที่ใช้อยู่ตอนนี้ (--default --docs = ค่าเริ่มต้นพร้อมคำอธิบาย)
+explain-config --option=themeดูคำอธิบายของค่าที่ระบุ
+validate-configตรวจว่าไฟล์ config มีจุดผิดไหม
+edit-configเปิดไฟล์ config
+ssh-cacheดูหรือจัดการรายการเซิร์ฟเวอร์ที่ติดตั้ง terminfo ของ Ghostty ไปแล้ว (ใช้คู่กับ ssh-terminfo ในหัวข้อ 11)

11ปัญหาที่เจอบ่อย

SSH เข้าเซิร์ฟเวอร์แล้วขึ้น unknown terminal type หรือปุ่ม/สีเพี้ยน

สาเหตุคือเซิร์ฟเวอร์ไม่รู้จัก xterm-ghostty ให้ใส่ใน config:

shell-integration-features = ssh-env,ssh-terminfo

หรือแก้เฉพาะครั้งด้วย TERM=xterm-256color ssh user@host

กด Option + ตัวอักษรแล้วได้สัญลักษณ์แปลกๆ เช่น ∫ แทนที่จะเป็นปุ่ม Alt

ใส่ macos-option-as-alt = true (หรือ left ถ้าต้องการเฉพาะ Option ด้านซ้าย)

แก้ config แล้วไม่เห็นผล

รัน ghostty +validate-config เพื่อดูว่ามีบรรทัดที่ผิดไหม จากนั้นกด ⌘ ⇧ , ถ้ายังไม่เห็นผล ให้ปิดแอปด้วย ⌘ Q แล้วเปิดใหม่

โปรแกรมใน terminal ขอสิทธิ์อ่าน clipboard

เป็นค่าเริ่มต้นที่ปลอดภัย (clipboard-read = ask) Ghostty จะถามก่อนทุกครั้งที่มีโปรแกรมขออ่าน clipboard ให้อนุญาตเฉพาะโปรแกรมที่รู้จัก

Quick Terminal กดแล้วไม่ขึ้น

ตรวจว่าตั้ง keybind = global:… ไว้แล้ว และ Ghostty ได้สิทธิ์ Accessibility (ดูหัวข้อ 8)
